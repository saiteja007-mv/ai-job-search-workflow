Grep the JD for EAD|OPT|CPT|F-1|F1|citizen|green card|clearance|sponsor and read each in context (F-1/OPT/EAD bar or citizenship/clearance requirement = hard skip; sponsorship absence is never a factor).

Record advertised comp verbatim, or "not stated".
